## ⚡ Tips Rápidos

1. **Siempre comprimir para web** - Las imágenes son 8K, usa herramientas como TinyPNG
2. **Lazy loading** - Carga imágenes below the fold de forma diferida
3. **Alt text SEO** - Usa descripciones ricas en keywords
4. **Responsive images** - Sirve diferentes tamaños según dispositivo
5. **WebP format** - Convierte a WebP para mejor performance
6. **CDN** - Usa CDN para servir imágenes rápidamente
7. **Caché** - Configura caché de navegador para imágenes estáticas
